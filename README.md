# ArduinoLab

**Learn Arduino. Build Circuits. Understand Code.**

🔗 **Live demo:** https://arduinolab-rho.vercel.app

ArduinoLab is a free, interactive, browser-based Arduino learning platform that makes electronics education easier and more accessible.

Supporting **English and Malayalam**, it lets learners explore electronic components, experiment with circuit connections, visualize circuits in 3D, and understand how hardware connects with programming.

<img width="100%" alt="ArduinoLab 3D workspace" src="https://github.com/user-attachments/assets/6f2e9f1a-5106-4bfe-a50f-5825e3baa755" />

## Key Features

- Interactive 3D Arduino workspace
- Circuit and component visualization
- Interactive circuit connections
- Dynamic Arduino code generation
- English and Malayalam support
- Beginner-friendly learning experience
- No software installation required

## Getting Started

Use it online at the live demo link above, or run it locally:

```bash
git clone https://github.com/msvasudevan/ArduinoLab.git
cd ArduinoLab
```

Then open `index.html` in your browser.
